# 🎾 網球對決

純前端（單一 `index.html`）的網球遊戲：你 vs 電腦，含完整網球計分（15/30/40、平分、佔先、搶七）、一發／二發、出界與掛網判定，三種難度，還能**和朋友連線對戰**。

## 玩法
- **移動**：方向鍵 / WASD（手機：左下搖桿）
- **擊球 / 發球**：空白鍵 或 J（發球：按一下拋球，球在最高點再按一下）
- **高吊球**：F（落點會在地上標出圓圈，圈縮到最小時球落地）；按住 ↓ 再按 F 是飛到十幾公尺高的**沖天球**
- **🔥 火球**：E（手機：「🔥火球」）。能量滿才能用，打出又快又燙的火球，落地會留下焦痕；能量靠回擊球和時間累積
- **跳五層樓高扣殺**：K（手機：「跳」）。一跳 15 公尺，旁邊有 1F～5F 刻度；在空中會自動飛向來球、對準高度扣殺，越高越快（空中按 E 是火焰扣殺）
- **後空翻擊球**：L（手機：「後翻」）。翻一圈打出強烈上旋，球又快又會急墜，擊球範圍也比較大
- **控制落點**：擊球瞬間按住 ← / →；揮拍時機越準，球越快越穩
- **擊球輔助**：提早按會先引拍等球、球來自動出拍；沒按左右時會自動往擊球點補位
- **暫停**：P

## 連線對戰
1. 一人按「建立房間」，把房間代碼或「複製邀請連結」傳給朋友
2. 朋友輸入代碼按「加入房間」（或直接打開邀請連結）
3. 連上後自動開始，雙方畫面都會把自己放在下方

使用 WebRTC 點對點連線（PeerJS），房主的瀏覽器負責運算比賽。少數公司／學校網路或行動網路可能無法建立點對點連線。

直接用瀏覽器開啟 `index.html` 即可遊玩，也透過 GitHub Pages 自動部署。
