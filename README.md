# 🎾 網球對決

純前端（單一 `index.html`）的網球遊戲：你 vs 電腦，含完整網球計分（15/30/40、平分、佔先、搶七）、一發／二發、出界與掛網判定（球沒落地就碰到圍欄算出界；落地後彈到圍欄算對方沒接到，都會立刻死球），三種難度，還能**和朋友連線對戰**。

## 玩法
- **移動**：方向鍵（手機：左下搖桿）
- **擊球 / 發球**：空白鍵 或 J（發球：按一下拋球，球在最高點再按一下）
- **特殊球都在左手 Q W A S D F**：Q 人球合一、W 跳、A 火球、S 魔球、D 後空翻、F 高吊球
- **高吊球**：F（落點會在地上標出圓圈，圈縮到最小時球落地）；按住 ↓ 再按 F 是飛到十幾公尺高的**沖天球**
- **🔥 火球**：A（手機：「🔥火球」）。能量滿才能用，打出又快又燙的火球，落地會留下焦痕；能量靠回擊球和時間累積
- **🐍 魔球**：S（手機：「🐍魔球」）。用半條能量打出左右蛇行的球，飛行中扭來扭去很難判斷，但落點不變；發球、扣殺時也能用
- **🌀 人球合一**：Q（手機：「🌀變球」）。擊球後整個人變成一顆帶著你臉的網球飛到對方球場，球一落地（或被對手截擊、掛網）就瞬移回原本的位置；發球、扣殺時也能用，電腦偶爾也會用
- **跳三層樓高扣殺**：W（手機：「跳」）。一跳 9 公尺，旁邊有 1F～3F 刻度；在空中會自動飛向來球、對準高度扣殺，越高越快（空中按 A 是火焰扣殺）
- **後空翻擊球**：D（手機：「後翻」）。翻一圈打出強烈上旋，球又快又會急墜，擊球範圍也比較大
- **控制落點**：擊球瞬間按住 ← / →；揮拍時機越準，球越快越穩
- **擊球輔助**：提早按會先引拍等球、球來自動出拍；沒按左右時會自動往擊球點補位
- **暫停**：P

## 連線對戰
1. 一人按「建立房間」，把房間代碼或「複製邀請連結」傳給朋友
2. 朋友輸入代碼按「加入房間」（或直接打開邀請連結）
3. 連上後自動開始，雙方畫面都會把自己放在下方
4. **💬 聊天**：聊天框一直開在畫面下方，點一下（電腦也可按 Enter）直接打字，按 Enter 就送出；打字時會出現「👍 好球！」「GG」等快捷語。訊息顯示在聊天框上方，並在說話的球員頭上冒出對話泡泡

使用 WebRTC 點對點連線（PeerJS），房主的瀏覽器負責運算比賽。少數公司／學校網路或行動網路可能無法建立點對點連線。

直接用瀏覽器開啟 `index.html` 即可遊玩，也透過 GitHub Pages 自動部署。
